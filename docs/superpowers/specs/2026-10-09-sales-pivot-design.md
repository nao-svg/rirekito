# リレキト for 営業職 — 営業特化への作り替え 設計書

日付: 2026-10-09
ブランチ: claude/resume-app-monetization-b0f6bd

## 背景・目的

- リレキトを「事務職特化」から「営業職への転職特化」へ置き換える。
- マネタイズ：同意した候補者を提携の転職エージェント（得意分野：営業・施工管理）へ送客し、1面談あたりで課金する。事務職ユーザーは送客先の対象外のため、事務職版は残さない。
- 主なターゲット：販売・接客・事務などから **未経験で営業へ転職する20代**。営業経験者も使える。
- 将来「for 施工管理」を追加できるよう、職種ごとに変わる文言は1か所にまとめる。

## 決定事項

| 項目 | 決定 |
|---|---|
| 事務職版 | 廃止し、営業版に置き換える |
| ターゲット | 未経験から営業への転職がメイン、経験者も利用可 |
| 診断タイプ | 営業スタイル6タイプ（下記） |
| 求人表示 | 「求人例（イメージ）」と明記し、送客への案内をつける |
| 同意文言 | 提供先の会社名・提供する情報・目的を明記する |

| H | 開拓ハンター | 行動量と切り替えの速さで新しい扉を開ける | 新規開拓営業 / 法人営業 / 代理店営業 | 行動力・切り替え力・チャレンジ精神 | #EF4444 |
| S | 課題ソルバー | 話を聞いて本当の困りごとを見抜き、解決策を提案する | IT・SaaS提案営業 / 人材営業 / 無形商材営業 | ヒアリング力・提案力・論理的思考 | #8B5CF6 |
| N | 数字ストラテジスト | 計画と分析で成果を再現性高く出す | インサイドセールス / 営業企画 / 反響営業 | 計画力・分析力・改善力 | #10B981 |
| K | 寄り添いカウンセラー | 相手の気持ちに寄り添い、大きな決断を後押しする | 住宅営業 / 保険営業 / 不動産カウンター営業 | 傾聴力・共感力・安心感 | #F59E0B |

selfPR（タイプごとの例文）の書き方：
- 200〜250字。「私は〜」で始め「貴社でも〜」で締める。
- 未経験の人を前提に「前職（販売・接客・事務など）の経験 → 営業で活きる強み」に言い換える構成にする。
- 具体的な数字の例を1つ入れる（例：常連のお客様30人以上を担当）。

## 3. 診断の質問と配点

各選択肢は「メインのタイプに2点・関連するタイプに1点」を加点する。どのタイプも、メインとして5回・関連として5回ずつ配点されるよう揃える。

| # | 質問 | A | B | C |
|---|---|---|---|---|
| 1 | 友達に好きなお店を勧めるとき、あなたは？ | 相手の好みを聞いてから合う店を選ぶ（S2,K1） | 「一回行ってみて！」と熱量で押す（H2,E1） | 味・値段・口コミなど根拠を並べる（N2,T1） |
| 2 | 初対面の人が多い場では？ | 自分から話しかけて輪を広げる（H2,E1） | 1人とじっくり話して仲良くなる（T2,K1） | 場を盛り上げて人と人をつなぐ（E2,H1） |
| 3 | 仕事やバイトで褒められたことに近いのは？ | 「常連さんに覚えられてるね」（T2,K1） | 「困ってることによく気づくね」（S2,N1） | 「売上・効率を上げてくれた」（N2,H1） |
| 4 | 目標が達成できそうにないとき、どうする？ | 行動量を増やして巻き返す（H2,N1） | やり方を分析して作戦を立て直す（N2,S1） | 周りに声をかけてみんなで乗り切る（E2,T1） |
| 5 | 相手に「考えておきます」と言われたら？ | 何が引っかかっているのか聞く（S2,N1） | 気持ちを尊重して、決めやすい時を待つ（K2,T1） | 時間をおいて連絡し、関係を続ける（T2,H1） |
| 6 | やりがいを感じる瞬間は？ | 「あなたに頼んでよかった」と言われたとき（K2,T1） | 誰もできなかったことを最初にやり遂げたとき（H2,S1） | チームで目標を達成したとき（E2,N1） |
| 7 | 好きな仕事の進め方は？ | 計画を立ててコツコツ積み上げる（T2,N1） | まず動いて、走りながら考える（H2,E1） | 相手と話しながら一緒に答えを作る（S2,K1） |
| 8 | 周りからよく言われるのは？ | 「話しやすい」「安心する」（K2,E1） | 「約束を守る」「信頼できる」（T2,K1） | 「説明がわかりやすい」（S2,E1） |
| 9 | 苦手なのは？ | 一人で黙々と作業し続けること（E2,H1） | 相手の気持ちを置き去りにして進めること（K2,S1） | 根拠がないまま感覚で進めること（N2,S1） |
| 10 | チームでの理想の役割は？ | みんなを引っ張るムードメーカー（E2,H1） | 一人ひとりの相談に乗るサポーター（K2,T1） | 情報を集めて方針を考える参謀（N2,S1） |

（T=信頼ビルダー, H=開拓ハンター, S=課題ソルバー, N=数字ストラテジスト, K=寄り添いカウンセラー, E=チーム推進エンジン）

### 同点のときの決め方（`calcDiagnosis`）

1. 合計点が最も高いタイプを候補にする。
2. 候補が複数あれば、メイン（2点）の加点を受けた回数が最も多いタイプに絞る。
3. それでも複数あれば、`h = Σ (回答インデックス+1) × 問題番号` を計算し、`候補[h % 候補数]` を選ぶ（候補はタイプ定義の順に並べる）。同じ回答なら必ず同じ結果になる。

試算（全 3^10 = 59,049 通りの回答）での各タイプの出現率は 16.2%〜17.2%。

## 4. 結果画面（Step3Result）

- 「向いている職種」→「向いている営業スタイル」
- 「あなたにおすすめの求人」→「このタイプが狙える求人例」。カード右上のバッジは「求人例」とし、カードの下に「※掲載内容はイメージです。実在の求人ではありません。」を表示する。
- 求人例の下に送客への案内ボックスを表示する（情報の入力欄は置かない）：
  「💼 実際の求人は、提携する人材紹介会社（{SITE.partnerName}）が無料でご紹介します。履歴書のダウンロード時に希望できます。」

### 求人例（jobs.ts）

`company` は「求人例」と表示する。給与は「年収◯◯万円〜（目安）」と表記する。

| タイプ | 求人例の職種 |
|---|---|
| 信頼ビルダー | 法人ルート営業（既存顧客中心・未経験歓迎） |
| 開拓ハンター | 新規開拓の法人営業（インセンティブあり） |
| 課題ソルバー | IT・SaaSの提案営業（研修充実） |
| 数字ストラテジスト | インサイドセールス（反響型・ノルマ過度なし） |
| 寄り添いカウンセラー | 住宅・保険の個人向け営業（反響型） |
| チーム推進エンジン | カスタマーサクセス（チームで顧客支援） |

## 5. AIによる自己PR（brushup-pr）

指示文の変更点：
- 役割：「あなたは{SITE.aiPersona}です。」
- 要件：
  - 200〜250字（現状どおり）
  - 入力された経験（販売・接客・事務など）を、営業で活きる強みに言い換える
  - 数字が入力されていれば必ず活かす
  - 誠実で前向き、営業への意欲が伝わる文体
  - 「私は〜」で始め「貴社でも〜」で締める（現状どおり）
- 入力の無害化処理・コードブロックの除去・モデル・出力の上限は現状のまま変えない。

入力欄の例文（Step4Resume）：
「例：アパレル販売で月の売上目標を6か月連続で達成。常連のお客様を30人以上担当していました。」

## 6. トップページ・メタ情報・同意文言

- ページタイトル：「リレキト for 営業職｜営業への転職書類、5分で完成。」
- 説明文：「リレキト for 営業職は、営業職への転職に特化した履歴書作成ツール。強みを診断するだけで営業向けの自己PRが完成し、そのまま履歴書PDFで出力できます。完全無料。」
- トップの見出し：「営業への転職書類、<br />5分で完成。」
- 「登録不要・完全無料」→「完全無料・5分で完成」（page.tsx、layout.tsx×2、opengraph-image.tsx）。PDF出力時に連絡先の登録が必須で、実態と合わないため。
- SNS用画像：ブランド名とキャッチコピーを表示する。
- 送客の同意文言（任意のチェック）：
  「氏名・連絡先・履歴書の内容・アンケート回答を、提携する人材紹介会社（{SITE.partnerName}）に提供し、営業職の求人紹介を受けることに同意する（任意）」
- プライバシーポリシーに「個人情報の第三者提供」の項目を追加する：提供先（{SITE.partnerName}）、提供する情報（氏名・連絡先・履歴書の内容・アンケート回答）、目的（求人の紹介）、同意した場合に限ること、提供の停止を求められること。

## 7. 確認方法

1. `npx tsc --noEmit`、`npm run lint`、`npm run build` が通ること。
2. 配点の検証スクリプトで、各タイプがメイン5回・関連5回であること、全回答パターンでの出現率が各15〜18%に収まることを確認する。
3. ブラウザで 入力 → 診断 → 結果 → 履歴書 → ダウンロード画面 を通しで操作する。結果画面・同意文言・トップページに新しい文言が出ていること、`grep -rn "事務" src` で事務職向けの文言が残っていないことを確認する。
